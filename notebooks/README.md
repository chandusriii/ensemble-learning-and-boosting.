# Notebooks

Run notebooks from the repository root after installing `requirements.txt`.

1. **AdaBoost:** weighted focus on examples previous weak learners misclassified.
2. **Gradient Boosting:** regressor and classifier, with regression and classification metrics.
3. **Voting and Stacking:** heterogeneous base models for classification and regression.
4. **XGBoost:** optimized gradient-boosted tree classifier.
5. **Blending:** validation-set predictions train a separate meta-model; the test set is retained for final evaluation.

All datasets are generated locally with scikit-learn, avoiding downloads.
